FalconMM Benutzerhandbuch

FalconMM ist eine Local-First-Mediathek: Screenshots, Bildschirmaufnahmen und Browser-Mitschnitte landen zur Prüfung im Posteingang, ein Tag-Baum ordnet die Materialien, ein optionales Vision-Modell (VLM) vergibt automatisch Tags, und über MCP können KI-Assistenten suchen.

Deutsch · v0.4.0 · Downloads · Alle Sprachen

1. Installation

  • macOS: Laden Sie FalconMM-0.4.0-arm64.dmg (Apple Silicon) oder FalconMM-0.4.0-x64.dmg (Intel) herunter, öffnen Sie das Image und ziehen Sie FalconMM in Programme. Das Build ist nicht notarisiert; klicken Sie beim ersten Start bei der macOS-Meldung mit der rechten Maustaste → Öffnen (oder unter Systemeinstellungen → Datenschutz & Sicherheit → Trotzdem öffnen).
  • Windows: Laden Sie FalconMM-Setup-0.4.0.exe herunter und folgen Sie dem Assistenten.
  • Beim ersten Start wird ein Bibliotheksordner angelegt (Standard: ~/Documents/FalconMM素材库); Datenbank und Medien bleiben lokal auf Ihrem Rechner.

2. Sprache der Oberfläche

Die App folgt standardmäßig Ihrer Systemsprache (11 Sprachen: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Der Wechsel ist jederzeit möglich unter Einstellungen → Allgemein & Updates → Sprache; Arabisch verwendet ein Layout von rechts nach links.

3. Software-Updates

  • Standardmäßig prüft die App beim Start die neueste Version im Release-Repository (github.com/darker2016/FalconMMRelease); das lässt sich in den Einstellungen deaktivieren.
  • Windows: Nach dem Download auf Update installieren klicken — das Installationsprogramm schließt die App und aktualisiert sie direkt; alle Daten und Einstellungen bleiben erhalten.
  • macOS: Nach dem Download öffnet Update installieren die heruntergeladene DMG; ziehen Sie FalconMM in Programme, um es zu ersetzen. Kopplung und Daten bleiben erhalten.

4. Browser-Erweiterung

  1. Laden Sie FalconMM-Extension-0.4.0.zip herunter und entpacken Sie das Archiv. Öffnen Sie chrome://extensions (Edge: edge://extensions), aktivieren Sie den Entwicklermodus → Entpackte Erweiterung laden → wählen Sie den entpackten Ordner extension.
  2. Klicken Sie auf das Symbol der Erweiterung und koppeln Sie sie nach den Hinweisen mit FalconMM (Einstellungen → Browser-Erweiterung → Kopplungscode erzeugen).
  3. Öffnen Sie das Popup auf einer beliebigen Seite, um Bilder / Videos in den Posteingang zu erfassen; auf unterstützten Websites können Sie Aktuelles Video herunterladen verwenden.

Unterstützte Websites: Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. Für internationale Websites muss Ihr Netzwerk darauf zugreifen können; YouTube / TikTok / X / Instagram / Vimeo haben keinen Tampermonkey-Fallback — Fehlschläge kommen immer mit einem konkreten Grund zurück. IQiYi / Youku / Tencent Video / MangoTV sind durch DRM geschützt und werden nicht zum Herunterladen angeboten.

5. Häufig genutzte Funktionen

  • Screenshot / Bildschirmaufnahme: ⌘/Ctrl+Shift+U für Screenshots, ⌘/Ctrl+Shift+K für Bildschirmaufnahmen (Tasten in den Einstellungen umbelegbar); die Ergebnisse landen direkt im Posteingang.
  • Posteingang: Einträge einzeln oder gesammelt „mit Tags versehen → archivieren“; die Archivierung ändert nur den Status, verschiebt die Originaldateien nicht und ist umkehrbar.
  • Tag-Baum: Klicken Sie in der Baumstruktur links auf Tags, um Medien zu filtern; „Nicht kategorisiert“ ist ein Systemknoten; aufwändige Bearbeitung erfolgt auf der Seite Tag-Verwaltung.
  • KI-Tags (optional): Einstellungen → KI-Tags akzeptiert jeden OpenAI-kompatiblen Endpunkt oder ein lokales Ollama; ohne Einrichtung bleiben andere Funktionen unberührt. Erkennungsergebnisse sind zunächst nur „Vorschläge“ und werden erst nach Bestätigung als feste Tags übernommen.
  • Import aus Drittanbieter-Bibliotheken: Einstellungen → Datensicherheit → Drittanbieter-Import (Eagle / Billfish / digiKam); die Quellbibliothek wird nur gelesen und die Medien in die Bibliothek kopiert.
  • MCP: Einstellungen → MCP ermöglicht Desktop-KI-Assistenten wie Claude, Medien über MCP zu finden.

6. Erweiterungsentwicklung

Quellcode der Erweiterung und das Entwicklerhandbuch werden im selben Release-Repository veröffentlicht (Ordner extension-source/, darin DEVELOPER.md). Für eine neue Website reicht es, nur die Erweiterung anzupassen: Websiteregister + Parser-Funktion + Seiten-Resolver; beim Handshake meldet die Erweiterung die neue Website automatisch an die Desktop-App, die den Download freigibt — Änderungen an der Desktop-App sind nicht nötig. Details siehe DEVELOPER.md.

7. Häufige Fragen

  • Download fehlgeschlagen / leere Datei: Website-URLs sind signiert und laufen schnell ab — laden Sie zuerst die Seite neu und klicken Sie dann auf Download; wenn es weiterhin scheitert, nennt die Fehlermeldung den konkreten Grund.
  • „App ist beschädigt“ (macOS): Folge der fehlenden Notarisierung — einmal per Rechtsklick → Öffnen starten; die App schließt danach ihre Eigenprüfung automatisch ab.
  • Update-Prüfung fehlgeschlagen: Zugriff auf api.github.com ist erforderlich; bei eingeschränktem Netzwerk später erneut versuchen.
