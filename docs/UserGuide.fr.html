Guide d’utilisation FalconMM

FalconMM est une médiathèque « local-first » : les captures d’écran, les enregistrements d’écran et les captures du navigateur passent par une boîte de réception pour validation, une arborescence de tags range les ressources, un modèle de vision (VLM) peut optionnellement étiqueter automatiquement, et MCP permet aux assistants IA d’effectuer des recherches.

Français · v0.4.0 · Téléchargements · Toutes les langues

1. Installation

  • macOS : téléchargez FalconMM-0.4.0-arm64.dmg (Apple silicon) ou FalconMM-0.4.0-x64.dmg (Intel), ouvrez-le puis faites glisser FalconMM dans Applications. Le build n’est pas notarié : au premier lancement, faites un clic droit → Ouvrir quand macOS le demande (ou passez par Réglages Système → Confidentialité et sécurité → Ouvrir quand même).
  • Windows : téléchargez FalconMM-Setup-0.4.0.exe et suivez l’assistant.
  • Au premier lancement, un dossier de bibliothèque est créé (par défaut ~/Documents/FalconMM素材库) ; la base de données et les médias restent sur votre machine.

2. Langue de l’interface

L’application suit par défaut la langue du système (11 langues : 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Vous pouvez changer de langue à tout moment dans Réglages → Général et mises à jour → Langue ; l’arabe utilise une mise en page de droite à gauche.

3. Mises à jour du logiciel

  • Par défaut, l’application vérifie au démarrage les dernières versions du dépôt de publication (github.com/darker2016/FalconMMRelease) ; ce comportement se désactive dans les réglages.
  • Windows : après le téléchargement, cliquez sur Installer la mise à jour — l’installateur ferme l’application et met à jour sur place, en conservant toutes les données et tous les réglages.
  • macOS : cliquez sur Installer la mise à jour pour ouvrir le DMG téléchargé, puis faites glisser FalconMM dans Applications pour le remplacer. L’appariement et les données sont conservés.

4. Extension navigateur

  1. Téléchargez FalconMM-Extension-0.4.0.zip et décompressez-le. Ouvrez chrome://extensions (Edge : edge://extensions), activez le Mode développeur → Charger l’extension non empaquetée → choisissez le dossier extension décompressé.
  2. Cliquez sur l’icône de l’extension et appariez-la avec FalconMM (Réglages → Extension navigateur → Générer un code d’appariement).
  3. Ouvrez la fenêtre contextuelle sur n’importe quelle page pour capturer des images / vidéos vers la boîte de réception ; sur les sites pris en charge, utilisez Télécharger la vidéo courante.

Sites pris en charge : Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. Les sites internationaux exigent que votre réseau puisse y accéder ; YouTube / TikTok / X / Instagram / Vimeo n’ont pas de solution de secours Tampermonkey — les échecs s’accompagnent toujours d’une raison précise. IQiYi / Youku / Tencent Video / MangoTV sont protégés par DRM et ne sont pas pris en charge pour le téléchargement.

5. Fonctions courantes

  • Capture d’écran / enregistrement : ⌘/Ctrl+Shift+U pour la capture d’écran, ⌘/Ctrl+Shift+K pour l’enregistrement de l’écran (raccourcis modifiables dans les réglages) ; les résultats arrivent directement dans la boîte de réception.
  • Boîte de réception : examinez les éléments un par un ou en lot, « étiqueter → archiver » ; l’archivage ne change que le statut sans déplacer les fichiers originaux, et il est réversible.
  • Arborescence d’étiquettes : cliquez sur les étiquettes de l’arborescence à gauche pour filtrer les médias ; « Non classé » est un nœud système ; les opérations avancées se font dans la page Gestion des étiquettes.
  • Étiquetage par IA (facultatif) : Réglages → Étiquetage IA accepte tout point de terminaison compatible OpenAI ou un Ollama local ; sans configuration, rien d’autre n’est affecté. Les résultats restent d’abord à l’état de « suggestion » et ne deviennent des étiquettes définitives qu’après confirmation.
  • Import de bibliothèques tierces : Réglages → Sécurité des données → import tiers (Eagle / Billfish / digiKam) ; la bibliothèque d’origine est lue sans modification et les médias sont copiés dans la bibliothèque.
  • MCP : Réglages → MCP permet aux assistants IA de bureau tels que Claude de retrouver vos médias via MCP.

6. Développement de l’extension

Le code source de l’extension et le guide du développeur sont publiés dans le même dépôt de publication (répertoire extension-source/, avec DEVELOPER.md). Ajouter un site ne touche que l’extension : registre des sites + fonction d’analyse + resolver de page ; lors du handshake, l’extension signale automatiquement les nouveaux sites à l’application de bureau pour autoriser leur téléchargement, sans modification du bureau. Voir DEVELOPER.md pour les détails.

7. FAQ

  • Échec du téléchargement / fichier vide : les URL des sites sont signées et expirent vite — rafraîchissez d’abord la page, puis réessayez ; en cas d’échec, consultez la raison précise indiquée par le message d’erreur.
  • « L’application est endommagée » (macOS) : cela vient de l’absence de notarisation ; un clic droit → Ouvrir suffit, et l’application termine ensuite automatiquement sa propre vérification.
  • Échec de la vérification des mises à jour : l’accès à api.github.com est nécessaire ; si le réseau est restreint, réessayez plus tard.
