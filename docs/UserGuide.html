FalconMM 使用说明 · User Guide · v0.4.0

FalconMM 是一个本地优先的素材库应用：截屏 / 录屏 / 浏览器抓取进入收件箱审核，标签树整理素材，可选接入视觉模型（VLM）自动打标签，并通过 MCP 供 AI 助手检索。

简体中文

1. 安装

  • macOS：下载 FalconMM-0.4.0-arm64.dmg（Apple 芯片）或 FalconMM-0.4.0-x64.dmg（Intel 芯片），打开后把 FalconMM 拖入「应用程序」。安装包未做公证，首次打开请在系统提示时右键 → 打开（或在「系统设置 → 隐私与安全性」点击「仍要打开」）。
  • Windows：下载 FalconMM-Setup-0.4.0.exe，按向导安装。
  • 首次启动会创建素材库目录（默认 ~/Documents/FalconMM素材库），数据库与素材都保存在本机。

2. 界面语言

安装后默认跟随系统语言（支持 11 种：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية）。可随时在 设置 → 通用与更新 → 界面语言 切换；阿拉伯语为从右到左布局。

3. 软件更新

  • 应用默认在启动时自动检查发布库（github.com/darker2016/FalconMMRelease）的最新版本，可在设置里关闭。
  • Windows：下载完成后点「安装更新」，安装器会自动关闭应用并完成升级（保留所有数据与设置）。
  • macOS：下载完成后点「安装更新」会打开 DMG 安装包，把 FalconMM 拖入「应用程序」替换即可；配对与数据保留。

4. 浏览器插件

  1. 下载 FalconMM-Extension-0.4.0.zip 并解压；打开 chrome://extensions（Edge: edge://extensions），开启「开发者模式」→「加载已解压的扩展程序」→ 选择解压后的 extension 目录。
  2. 点击扩展图标，按提示与 FalconMM 配对（设置 → 浏览器插件 → 生成配对码）。
  3. 在网页上打开弹窗即可抓取图片 / 视频到收件箱；受支持站点的视频可点「直接下载」。

支持的站点：哔哩哔哩、抖音、小红书、YouTube、TikTok、X (Twitter)、Instagram、 Vimeo。国际站点需要你的网络可以访问对应站点；YouTube / TikTok / X / Instagram / Vimeo 没有 Tampermonkey 兜底脚本，解析失败会给出明确原因。爱奇艺 / 优酷 / 腾讯视频 / 芒果TV 受版权保护（DRM），不做下载。

5. 常用功能

  • 截屏 / 录屏：⌘/Ctrl+Shift+U 截图、⌘/Ctrl+Shift+K 录屏（可在设置改键），产物直接进入收件箱。
  • 收件箱：逐项或批量「打标签 → 归档」；归档只改状态不移动原文件，可撤销。
  • 标签树：左侧树点选过滤素材；「未归类」是系统节点；复杂操作在「标签管理」页。
  • AI 打标签（可选）：设置 → AI 识别，添加任意 OpenAI 兼容端点或本地 Ollama；未配置不影响其他功能。识别结果默认为「建议态」，确认后才写入正式标签。
  • 第三方素材库导入：设置 → 数据安全 → 第三方导入（Eagle / Billfish / digiKam），只读原库并复制入库。
  • MCP：设置 → MCP，可让 Claude 等桌面 AI 通过 MCP 检索素材。

6. 插件开发

插件源码与开发者指南发布在同一发布库（extension-source/ 目录，含 DEVELOPER.md）。新增站点只需修改插件：站点注册表 + 解析函数 + 页面 resolver；插件握手时会自动把新站点上报给桌面端放行下载，无需修改桌面端。详见 DEVELOPER.md。

7. 常见问题

  • 下载失败 / 空文件：站点地址常带签名与时效，先刷新页面再点下载；仍失败请看错误提示的具体原因。
  • 「应用已损坏」（macOS）：安装包未公证所致，右键打开一次即可；应用随后会自动完成自签校验。
  • 检查更新失败：需要能访问 api.github.com；网络受限时稍后重试。

English

1. Install

  • macOS: download FalconMM-0.4.0-arm64.dmg (Apple silicon) or FalconMM-0.4.0-x64.dmg (Intel), open it and drag FalconMM into Applications. The build is not notarized; on first launch right-click → Open when macOS asks (or use System Settings → Privacy & Security → Open Anyway).
  • Windows: download FalconMM-Setup-0.4.0.exe and follow the wizard.
  • On first launch a library folder is created (default ~/Documents/FalconMM素材库); the database and assets stay on your machine.

2. Interface language

The app follows your system language by default (11 languages: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Switch any time in Settings → General & Updates → Language; Arabic uses a right-to-left layout.

3. Software updates

  • By default the app checks the release repository (github.com/darker2016/FalconMMRelease) at startup; this can be disabled in Settings.
  • Windows: click Install update after download — the installer closes the app and upgrades in place, keeping all data and settings.
  • macOS: click Install update to open the downloaded DMG, then drag FalconMM into Applications to replace it. Pairing and data are preserved.

4. Browser extension

  1. Download FalconMM-Extension-0.4.0.zip and unzip it. Open chrome://extensions (Edge: edge://extensions), enable Developer mode → Load unpacked → pick the unzipped extension folder.
  2. Click the extension icon and pair it with FalconMM (Settings → Browser extension → Generate pairing code).
  3. Open the popup on any page to capture images / videos into the Inbox; on supported sites use Download current video.

Supported sites: Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. International sites require that your network can reach them; YouTube / TikTok / X / Instagram / Vimeo have no Tampermonkey fallback — failures come back with a specific reason. IQiYi / Youku / Tencent Video / MangoTV are DRM-protected and not supported for download.

5. Everyday features

  • Screenshot / recording: ⌘/Ctrl+Shift+U screenshot, ⌘/Ctrl+Shift+K screen recording (rebindable in Settings); results land in the Inbox.
  • Inbox: review items, tag, then Archive (status-only, reversible, originals untouched).
  • Tag tree: click tags in the sidebar to filter; "Uncategorized" is a system node; heavy editing lives in Tag management.
  • AI tagging (optional): Settings → AI tagging accepts any OpenAI-compatible endpoint or local Ollama; suggestions stay in a pending state until you apply them.
  • Third-party import: Settings → Data safety → import from Eagle / Billfish / digiKam (read-only on the source library).
  • MCP: Settings → MCP lets desktop AI assistants such as Claude search your library.

6. Extension development

Extension source code and a developer guide are published in the same release repository (extension-source/, see DEVELOPER.md). Adding a site only touches the extension — site registry, parser, page resolver — and the extension auto-registers new sites with the desktop app during handshake. No desktop changes needed.

7. FAQ

  • Download failed / empty file: site URLs are signed and expire quickly — refresh the page first, then retry; errors always explain the cause.
  • "App is damaged" (macOS): caused by the missing notarization; right-click → Open once and the app will finish its own verification.
  • Update check failed: requires access to api.github.com; retry later on restricted networks.

繁體中文

1. 安裝

  • macOS：下載 FalconMM-0.4.0-arm64.dmg（Apple 晶片）或 FalconMM-0.4.0-x64.dmg（Intel 晶片），打開後把 FalconMM 拖入「應用程式」。安裝檔未做公證，首次開啟請在系統提示時按右鍵 → 打開（或在「系統設定 → 隱私權與安全性」點擊「仍要打開」）。
  • Windows：下載 FalconMM-Setup-0.4.0.exe，依安裝精靈指示安裝。
  • 首次啟動會建立素材庫資料夾（預設 ~/Documents/FalconMM素材库），資料庫與素材都儲存在本機。

2. 介面語言

安裝後預設跟隨系統語言（支援 11 種：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية）。可隨時在 設定 → 一般與更新 → 介面語言 切換；阿拉伯語為由右至左版面。

3. 軟體更新

  • 應用程式預設會在啟動時自動檢查發布庫（github.com/darker2016/FalconMMRelease）的最新版本，可在設定中關閉。
  • Windows：下載完成後點「安裝更新」，安裝程式會自動關閉應用程式並完成升級（保留所有資料與設定）。
  • macOS：下載完成後點「安裝更新」會開啟 DMG 安裝檔，把 FalconMM 拖入「應用程式」取代即可；配對與資料都會保留。

4. 瀏覽器擴充功能

  1. 下載 FalconMM-Extension-0.4.0.zip 並解壓縮；開啟 chrome://extensions（Edge：edge://extensions），開啟「開發人員模式」→「載入未封裝項目」→ 選擇解壓縮後的 extension 資料夾。
  2. 點擊擴充功能圖示，依提示與 FalconMM 配對（設定 → 瀏覽器擴充功能 → 產生配對碼）。
  3. 在網頁上開啟彈出視窗即可擷取圖片 / 影片到收件匣；受支援站點的影片可點「直接下載」。

支援的站點：Bilibili、Douyin、Xiaohongshu（RedNote）、YouTube、TikTok、X (Twitter)、Instagram、Vimeo。國際站點需要你的網路可以連上對應網站；YouTube / TikTok / X / Instagram / Vimeo 沒有 Tampermonkey 備援腳本，解析失敗會給出明確原因。IQiYi / Youku / Tencent Video / MangoTV 受版權保護（DRM），不開放下載。

5. 常用功能

  • 截圖 / 錄影：⌘/Ctrl+Shift+U 截圖、⌘/Ctrl+Shift+K 錄影（可在設定變更快捷鍵），產出直接進入收件匣。
  • 收件匣：逐筆或批次「加標籤 → 歸檔」；歸檔只變更狀態、不搬移原始檔案，可復原。
  • 標籤樹：點選左側樹狀標籤即可篩選素材；「未分類」是系統節點；複雜操作請到「標籤管理」頁。
  • AI 自動標籤（選用）：設定 → AI 辨識，可加入任何 OpenAI 相容端點或本機 Ollama；未設定不影響其他功能。辨識結果預設為「建議狀態」，確認後才會寫入正式標籤。
  • 第三方素材庫匯入：設定 → 資料安全 → 第三方匯入（Eagle / Billfish / digiKam），僅唯讀原庫並複製入庫。
  • MCP：設定 → MCP，可讓 Claude 等桌面 AI 透過 MCP 檢索素材。

6. 擴充功能開發

擴充功能原始碼與開發者指南發布在同一發布庫（extension-source/ 目錄，內含 DEVELOPER.md）。新增站點只需修改擴充功能：站點註冊表 + 解析函式 + 頁面 resolver；擴充功能握手時會自動將新站點回報給桌面端放行下載，無須修改桌面端。詳見 DEVELOPER.md。

7. 常見問題

  • 下載失敗 / 檔案為空：站點網址常帶簽名與時效，請先重新整理頁面再點下載；仍失敗請查看錯誤提示的具體原因。
  • 「應用程式已損壞」（macOS）：安裝檔未公證所致，按右鍵開啟一次即可；應用程式之後會自動完成自我簽署驗證。
  • 檢查更新失敗：需要能連上 api.github.com；網路受限時請稍後再試。

日本語

1. インストール

  • macOS：FalconMM-0.4.0-arm64.dmg（Apple シリコン）または FalconMM-0.4.0-x64.dmg（Intel）をダウンロードして開き、FalconMM を「アプリケーション」へドラッグします。ビルドは公証されていないため、初回起動時に macOS に確認されたら右クリック → 開くを選んでください（または「システム設定 → プライバシーとセキュリティ」で「このまま開く」）。
  • Windows：FalconMM-Setup-0.4.0.exe をダウンロードし、ウィザードに従ってインストールします。
  • 初回起動時にライブラリフォルダー（既定は ~/Documents/FalconMM素材库）が作成され、データベースと素材はすべてこの端末内に保存されます。

2. 表示言語

既定ではシステムの言語に従います（11 言語対応：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية）。「設定 → 一般とアップデート → 言語」からいつでも変更でき、アラビア語は右から左（RTL）のレイアウトになります。

3. ソフトウェアアップデート

  • 既定で、起動時にリリースリポジトリ（github.com/darker2016/FalconMMRelease）の最新バージョンを自動確認します。設定でオフにできます。
  • Windows：ダウンロード後「アップデートをインストール」をクリックすると、インストーラーがアプリを閉じてその場でアップグレードします（データと設定はすべて保持されます）。
  • macOS：「アップデートをインストール」をクリックするとダウンロード済みの DMG が開くので、FalconMM を「アプリケーション」へドラッグして入れ替えてください。ペアリングとデータは保持されます。

4. ブラウザー拡張機能

  1. FalconMM-Extension-0.4.0.zip をダウンロードして解凍します。chrome://extensions（Edge は edge://extensions）を開き、「デベロッパー モード」を有効化 →「パッケージされていない拡張機能を読み込む」→ 解凍した extension フォルダーを選択します。
  2. 拡張機能のアイコンをクリックし、案内に従って FalconMM とペアリングします（設定 → ブラウザー拡張機能 → ペアリングコードを生成）。
  3. Web ページでポップアップを開くと、画像 / 動画を受信トレイに取り込めます。対応サイトの動画は「現在の動画をダウンロード」で直接ダウンロードできます。

対応サイト：Bilibili、Douyin、Xiaohongshu（RedNote）、YouTube、TikTok、X (Twitter)、Instagram、Vimeo。国際サイトはネットワークからアクセスできる必要があります。YouTube / TikTok / X / Instagram / Vimeo には Tampermonkey のフォールバックがないため、解析に失敗した場合は具体的な理由が表示されます。IQiYi / Youku / Tencent Video / MangoTV は DRM で保護されており、ダウンロードには対応していません。

5. よく使う機能

  • スクリーンショット / 録画：⌘/Ctrl+Shift+U でスクリーンショット、⌘/Ctrl+Shift+K で画面録画（設定で変更可能）。結果はそのまま受信トレイに入ります。
  • 受信トレイ：項目を一件ずつまたはまとめて「タグを付け → アーカイブ」。アーカイブは状態を変えるだけで元ファイルは移動せず、取り消しもできます。
  • タグツリー：左のツリーでタグをクリックすると素材を絞り込めます。「未分類」はシステムノードです。本格的な編集は「タグ管理」ページで行います。
  • AI タグ付け（任意）：設定 → AI タグ付けで、OpenAI 互換エンドポイントやローカルの Ollama を追加できます。未設定でも他の機能には影響しません。認識結果はまず「提案状態」となり、確定してはじめて正式なタグとして書き込まれます。
  • 外部ライブラリの取り込み：設定 → データ保護 → 外部取り込み（Eagle / Billfish / digiKam）。元のライブラリは読み取り専用とし、コピーして取り込みます。
  • MCP：設定 → MCP で、Claude などのデスクトップ AI が MCP 経由で素材を検索できます。

6. 拡張機能の開発

拡張機能のソースコードと開発者ガイドは同じリリースリポジトリで公開しています（extension-source/ ディレクトリ、DEVELOPER.md 参照）。サイトの追加は拡張機能側の修正だけで完了します。サイト登録表 + 解析関数 + ページ resolver を追加すると、拡張機能がハンドシェイク時に新しいサイトをデスクトップ側へ自動報告してダウンロードを許可します。デスクトップ側の変更は不要です。詳細は DEVELOPER.md を参照してください。

7. よくある質問

  • ダウンロード失敗 / 空ファイル：サイトの URL は署名付きで有効期限が短いため、まずページを再読み込みしてからダウンロードしてください。それでも失敗する場合は、エラー表示の具体的な原因をご確認ください。
  • 「アプリが壊れています」（macOS）：公証されていないことが原因です。右クリック →「開く」を一度実行すればよく、その後アプリが自己検証を完了します。
  • アップデート確認に失敗する：api.github.com へのアクセスが必要です。ネットワークが制限されている環境では後ほど再試行してください。

한국어

1. 설치

  • macOS: FalconMM-0.4.0-arm64.dmg(Apple 실리콘) 또는 FalconMM-0.4.0-x64.dmg(Intel)를 내려받아 열고 FalconMM을 '응용 프로그램'으로 드래그해요. 빌드가 공증되지 않았기 때문에 처음 열 때 macOS가 물으면 오른쪽 클릭 → 열기를 선택해요(또는 '시스템 설정 → 개인정보 보호 및 보안'에서 '확인 없이 열기'를 눌러요).
  • Windows: FalconMM-Setup-0.4.0.exe를 내려받아 마법사에 따라 설치해요.
  • 첫 실행 시 라이브러리 폴더(기본값 ~/Documents/FalconMM素材库)가 만들어지고, 데이터베이스와 소재는 모두 이 컴퓨터에 저장돼요.

2. 인터페이스 언어

기본적으로 시스템 언어를 따라요(11개 언어 지원: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). '설정 → 일반 및 업데이트 → 언어'에서 언제든 바꿀 수 있고, 아랍어는 오른쪽에서 왼쪽(RTL) 레이아웃으로 표시돼요.

3. 소프트웨어 업데이트

  • 앱은 기본적으로 시작할 때 릴리스 저장소(github.com/darker2016/FalconMMRelease)의 최신 버전을 자동으로 확인해요. 설정에서 끌 수 있어요.
  • Windows: 내려받기가 끝나면 '업데이트 설치'를 눌러요. 설치 프로그램이 앱을 닫고 그 자리에서 업그레이드하며, 데이터와 설정은 모두 유지돼요.
  • macOS: '업데이트 설치'를 누르면 내려받은 DMG가 열려요. FalconMM을 '응용 프로그램'으로 드래그해 덮어쓰면 돼요. 페어링과 데이터는 그대로 유지돼요.

4. 브라우저 확장

  1. FalconMM-Extension-0.4.0.zip을 내려받아 압축을 풀어요. chrome://extensions(Edge는 edge://extensions)를 연 뒤 '개발자 모드'를 켜고 → '압축해제된 확장 프로그램을 로드합니다' → 압축을 푼 extension 폴더를 선택해요.
  2. 확장 아이콘을 눌러 안내에 따라 FalconMM과 페어링해요(설정 → 브라우저 확장 → 페어링 코드 생성).

6. Desenvolvimento da extensão

O código-fonte da extensão e o guia do desenvolvedor são publicados no mesmo repositório de versões (pasta extension-source/, com DEVELOPER.md). Adicionar um site mexe só na extensão: registro de sites + função de análise + resolver de página; no handshake, a extensão informa automaticamente os sites novos ao aplicativo de desktop para liberar o download, sem precisar mudar o desktop. Veja o DEVELOPER.md para detalhes.

7. Perguntas frequentes

  • Falha no download / arquivo vazio: as URLs dos sites são assinadas e expiram rápido — atualize a página primeiro e clique de novo no download; se continuar falhando, veja o motivo específico indicado no erro.
  • “O aplicativo está danificado” (macOS): é por falta de notarização — basta abrir uma vez com o botão direito → Abrir; depois o aplicativo conclui a própria verificação automaticamente.
  • Falha ao verificar atualizações: é preciso acesso a api.github.com; com a rede restrita, tente mais tarde.

Русский

1. Установка

  • macOS: скачайте FalconMM-0.4.0-arm64.dmg (Apple silicon) или FalconMM-0.4.0-x64.dmg (Intel), откройте образ и перетащите FalconMM в папку «Программы». Сборка не нотаризована: при первом запуске, когда macOS покажет запрос, нажмите правой кнопкой мыши → «Открыть» (или в «Системных настройках → Конфиденциальность и безопасность» нажмите «Все равно открыть»).
  • Windows: скачайте FalconMM-Setup-0.4.0.exe и следуйте шагам мастера установки.
  • При первом запуске создаётся папка библиотеки (по умолчанию ~/Documents/FalconMM素材库); база данных и материалы хранятся локально на вашем компьютере.

2. Язык интерфейса

По умолчанию приложение следует языку системы (11 языков: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Сменить язык можно в любой момент: Настройки → Общие и обновления → Язык; арабский использует интерфейс справа налево.

3. Обновления приложения

  • По умолчанию при запуске приложение проверяет последнюю версию в репозитории релизов (github.com/darker2016/FalconMMRelease); проверку можно отключить в настройках.
  • Windows: после загрузки нажмите «Установить обновление» — установщик закроет приложение и обновит его на месте, сохранив все данные и настройки.
  • macOS: нажмите «Установить обновление», откроется загруженный образ DMG — перетащите FalconMM в «Программы», чтобы заменить его. Сопряжение и данные сохраняются.

4. Браузерное расширение

  1. Скачайте FalconMM-Extension-0.4.0.zip и распакуйте архив. Откройте chrome://extensions (Edge: edge://extensions), включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите распакованную папку extension.
  2. Нажмите значок расширения и выполните сопряжение с FalconMM по подсказкам (Настройки → Браузерное расширение → Создать код сопряжения).
  3. Открывайте всплывающее окно на любой странице, чтобы отправлять изображения / видео во входящие; на поддерживаемых сайтах доступна кнопка «Скачать текущее видео».

Поддерживаемые сайты: Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. Для международных сайтов нужно, чтобы ваша сеть имела к ним доступ; у YouTube / TikTok / X / Instagram / Vimeo нет резервного сценария Tampermonkey — при сбое всегда сообщается конкретная причина. IQiYi / Youku / Tencent Video / MangoTV защищены DRM, их загрузка не поддерживается.

5. Основные функции

  • Снимок экрана / запись: ⌘/Ctrl+Shift+U — снимок экрана, ⌘/Ctrl+Shift+K — запись экрана (клавиши переназначаются в настройках); результаты сразу попадают во входящие.
  • Входящие: разбирайте элементы по одному или пакетно — «поставить теги → в архив»; архивация меняет только статус, не перемещает исходные файлы и отменяется.
  • Дерево тегов: нажимайте теги в дереве слева, чтобы фильтровать материалы; «Без категории» — системный узел; расширенные операции — на странице управления тегами.
  • Теги ИИ (необязательно): Настройки → ИИ-теги принимают любой совместимый с OpenAI эндпоинт или локальный Ollama; без настройки остальные функции не затрагиваются. Результаты распознавания сначала хранятся как «предложения» и записываются как постоянные теги только после подтверждения.
  • Импорт из сторонних библиотек: Настройки → Безопасность данных → импорт из сторонних библиотек (Eagle / Billfish / digiKam); исходная библиотека открывается только для чтения, материалы копируются в библиотеку.
  • MCP: Настройки → MCP позволяет настольным ИИ-ассистентам вроде Claude искать материалы через MCP.

6. Разработка расширения

Исходный код расширения и руководство для разработчиков публикуются в том же репозитории релизов (каталог extension-source/, в нём DEVELOPER.md). Чтобы добавить сайт, достаточно изменить только расширение: реестр сайтов + функция разбора + резолвер страницы; при хендшейке расширение автоматически сообщает новые сайты настольному приложению, чтобы разрешить их загрузку, — менять настольное приложение не нужно. Подробности в DEVELOPER.md.

7. Часто задаваемые вопросы

  • Ошибка загрузки / пустой файл: ссылки сайтов подписаны и быстро устаревают — сначала обновите страницу и снова нажмите загрузку; если не помогло, смотрите конкретную причину в сообщении об ошибке.
  • «Приложение повреждено» (macOS): следствие отсутствия нотаризации — достаточно один раз открыть приложение правой кнопкой → «Открыть»; после этого приложение само завершит проверку подписи.
  • Не удаётся проверить обновления: требуется доступ к api.github.com; при ограниченной сети повторите попытку позже.

العربية

1. التثبيت

  • macOS: نزّل FalconMM-0.4.0-arm64.dmg (معالجات Apple) أو FalconMM-0.4.0-x64.dmg (Intel)، ثم افتح الملف واسحب FalconMM إلى مجلد «التطبيقات». النسخة غير موثّقة، فعند أول تشغيل انقر بزر الفأرة الأيمن ← فتح عندما يطلب macOS ذلك (أو من «إعدادات النظام ← الخصوصية والأمان» انقر «فتح على أي حال»).
  • Windows: نزّل FalconMM-Setup-0.4.0.exe واتبع خطوات معالج الإعداد.
  • عند أول تشغيل يُنشأ مجلد المكتبة (افتراضيًا ~/Documents/FalconMM素材库)، وتبقى قاعدة البيانات والملفات على جهازك محليًا.

2. لغة الواجهة

يتبع التطبيق افتراضيًا لغة النظام (11 لغة: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). يمكنك التبديل في أي وقت من الإعدادات ← عام وتحديثات ← اللغة؛ وتُعرض العربية باتجاه من اليمين إلى اليسار.

3. تحديثات البرنامج

  • يتحقق التطبيق افتراضيًا عند بدء التشغيل من أحدث إصدار في مستودع الإصدارات (github.com/darker2016/FalconMMRelease)، ويمكن تعطيل ذلك من الإعدادات.
  • Windows: بعد اكتمال التنزيل انقر «تثبيت التحديث»، فيغلق المُثبِّت التطبيق ويحدّثه في مكانه مع الاحتفاظ بجميع البيانات والإعدادات.
  • macOS: انقر «تثبيت التحديث» ليُفتح ملف DMG الذي نُزِّل، ثم اسحب FalconMM إلى «التطبيقات» ليحل محله؛ يُحتفظ بالاقتران والبيانات.

4. إضافة المتصفح

  1. نزّل FalconMM-Extension-0.4.0.zip وفكّ ضغطه. افتح chrome://extensions (وفي Edge: edge://extensions)، وفعّل «وضع المطوّر» ← «تحميل إضافة غير مضغوطة» ← اختر مجلد extension بعد فك الضغط.
  2. انقر أيقونة الإضافة واقترنها مع FalconMM وفق التعليمات (الإعدادات ← إضافة المتصفح ← إنشاء رمز الاقتران).
  3. افتح النافذة المنبثقة على أي صفحة لالتقاط الصور / الفيديوهات إلى صندوق الوارد؛ وفي المواقع المدعومة يمكنك النقر على «تنزيل الفيديو الحالي».

المواقع المدعومة: Bilibili وDouyin وXiaohongshu (RedNote) وYouTube وTikTok وX (Twitter) وInstagram وVimeo. تتطلب المواقع الدولية أن تتمكن شبكتك من الوصول إليها؛ ولا يتوفر لـ YouTube / TikTok / X / Instagram / Vimeo بديل عبر Tampermonkey، ويظهر عند التعذر سبب واضح ومحدد. أما IQiYi / Youku / Tencent Video / MangoTV فهي محمية بحقوق النشر (DRM) ولا يُتاح تنزيلها.

5. الوظائف اليومية

  • لقطة الشاشة / التسجيل: ⌘/Ctrl+Shift+U لقطة شاشة، و⌘/Ctrl+Shift+K تسجيل الشاشة (يمكن تغيير الاختصارات من الإعدادات)، وتذهب النتائج مباشرة إلى صندوق الوارد.
  • صندوق الوارد: راجع العناصر واحدة تلو الأخرى أو دفعة واحدة «وسمها ← أرشفتها»؛ الأرشفة تغيّر الحالة فقط دون نقل الملفات الأصلية ويمكن التراجع عنها.
  • شجرة الوسوم: انقر الوسوم في الشجرة الجانبية لتصفية المواد؛ «غير المصنّف» عقدة نظامية؛ والعمليات المتقدمة تجري في صفحة «إدارة الوسوم».
  • الوسم بالذكاء الاصطناعي (اختياري): الإعدادات ← الوسم بالذكاء الاصطناعي، ويمكن إضافة أي نقطة نهاية متوافقة مع OpenAI أو Ollama محلي؛ وعدم الإعداد لا يؤثر على بقية الوظائف. تظهر نتائج التعرف أولًا كـ«اقتراحات» ولا تُكتب وسومًا رسمية إلا بعد تأكيدها.
  • استيراد مكتبات الأطراف الأخرى: الإعدادات ← أمان البيانات ← استيراد من الأطراف الأخرى (Eagle / Billfish / digiKam)؛ تُقرأ المكتبة الأصلية دون تعديل وتُنسخ المواد إلى المكتبة.
  • MCP: الإعدادات ← MCP، ويتيح ذلك لمساعدي الذكاء الاصطناعي على سطح المكتب مثل Claude البحث عن موادك عبر MCP.

6. تطوير الإضافات

يُنشر الكود المصدري للإضافة ودليل المطوّر في مستودع الإصدارات نفسه (مجلد extension-source/، وبه DEVELOPER.md). لإضافة موقع جديد يكفي تعديل الإضافة فقط: سجل المواقع + دالة التحليل + محلّل الصفحة (resolver)؛ فعند المصافحة (handshake) تُبلّغ الإضافة الموقعَ الجديد تلقائيًا إلى تطبيق سطح المكتب للسماح بتنزيله، دون أي تعديل على تطبيق سطح المكتب. راجع DEVELOPER.md لمزيد من التفاصيل.
