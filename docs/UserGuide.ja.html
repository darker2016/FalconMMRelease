FalconMM ご利用ガイド

FalconMM はローカルファーストの素材ライブラリです。スクリーンショット・画面録画・ブラウザからのキャプチャを受信箱で確認し、タグツリーで素材を整理します。オプションで視覚モデル（VLM）による自動タグ付けや、MCP 経由での AI アシスタントからの検索にも対応します。

1. インストール

  • macOS：FalconMM-0.4.0-arm64.dmg（Apple シリコン）または FalconMM-0.4.0-x64.dmg（Intel）をダウンロードして開き、FalconMM を「アプリケーション」へドラッグします。ビルドは公証されていないため、初回起動時に macOS に確認されたら右クリック → 開くを選んでください（または「システム設定 → プライバシーとセキュリティ」で「このまま開く」）。
  • Windows：FalconMM-Setup-0.4.0.exe をダウンロードし、ウィザードに従ってインストールします。
  • 初回起動時にライブラリフォルダー（既定は ~/Documents/FalconMM素材库）が作成され、データベースと素材はすべてこの端末内に保存されます。

2. 表示言語

既定ではシステムの言語に従います（11 言語対応：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية）。「設定 → 一般とアップデート → 言語」からいつでも変更でき、アラビア語は右から左（RTL）のレイアウトになります。

3. ソフトウェアアップデート

  • 既定で、起動時にリリースリポジトリ（github.com/darker2016/FalconMMRelease）の最新バージョンを自動確認します。設定でオフにできます。
  • Windows：ダウンロード後「アップデートをインストール」をクリックすると、インストーラーがアプリを閉じてその場でアップグレードします（データと設定はすべて保持されます）。
  • macOS：「アップデートをインストール」をクリックするとダウンロード済みの DMG が開くので、FalconMM を「アプリケーション」へドラッグして入れ替えてください。ペアリングとデータは保持されます。

4. ブラウザー拡張機能

  1. FalconMM-Extension-0.4.0.zip をダウンロードして解凍します。chrome://extensions（Edge は edge://extensions）を開き、「デベロッパー モード」を有効化 →「パッケージされていない拡張機能を読み込む」→ 解凍した extension フォルダーを選択します。
  2. 拡張機能のアイコンをクリックし、案内に従って FalconMM とペアリングします（設定 → ブラウザー拡張機能 → ペアリングコードを生成）。
  3. Web ページでポップアップを開くと、画像 / 動画を受信トレイに取り込めます。対応サイトの動画は「現在の動画をダウンロード」で直接ダウンロードできます。

対応サイト：Bilibili、Douyin、Xiaohongshu（RedNote）、YouTube、TikTok、X (Twitter)、Instagram、Vimeo。国際サイトはネットワークからアクセスできる必要があります。YouTube / TikTok / X / Instagram / Vimeo には Tampermonkey のフォールバックがないため、解析に失敗した場合は具体的な理由が表示されます。IQiYi / Youku / Tencent Video / MangoTV は DRM で保護されており、ダウンロードには対応していません。

5. よく使う機能

  • スクリーンショット / 録画：⌘/Ctrl+Shift+U でスクリーンショット、⌘/Ctrl+Shift+K で画面録画（設定で変更可能）。結果はそのまま受信トレイに入ります。
  • 受信トレイ：項目を一件ずつまたはまとめて「タグを付け → アーカイブ」。アーカイブは状態を変えるだけで元ファイルは移動せず、取り消しもできます。
  • タグツリー：左のツリーでタグをクリックすると素材を絞り込めます。「未分類」はシステムノードです。本格的な編集は「タグ管理」ページで行います。
  • AI タグ付け（任意）：設定 → AI タグ付けで、OpenAI 互換エンドポイントやローカルの Ollama を追加できます。未設定でも他の機能には影響しません。認識結果はまず「提案状態」となり、確定してはじめて正式なタグとして書き込まれます。
  • 外部ライブラリの取り込み：設定 → データ保護 → 外部取り込み（Eagle / Billfish / digiKam）。元のライブラリは読み取り専用とし、コピーして取り込みます。
  • MCP：設定 → MCP で、Claude などのデスクトップ AI が MCP 経由で素材を検索できます。

6. 拡張機能の開発

拡張機能のソースコードと開発者ガイドは同じリリースリポジトリで公開しています（extension-source/ ディレクトリ、DEVELOPER.md 参照）。サイトの追加は拡張機能側の修正だけで完了します。サイト登録表 + 解析関数 + ページ resolver を追加すると、拡張機能がハンドシェイク時に新しいサイトをデスクトップ側へ自動報告してダウンロードを許可します。デスクトップ側の変更は不要です。詳細は DEVELOPER.md を参照してください。

7. よくある質問

  • ダウンロード失敗 / 空ファイル：サイトの URL は署名付きで有効期限が短いため、まずページを再読み込みしてからダウンロードしてください。それでも失敗する場合は、エラー表示の具体的な原因をご確認ください。
  • 「アプリが壊れています」（macOS）：公証されていないことが原因です。右クリック →「開く」を一度実行すればよく、その後アプリが自己検証を完了します。
  • アップデート確認に失敗する：api.github.com へのアクセスが必要です。ネットワークが制限されている環境では後ほど再試行してください。
