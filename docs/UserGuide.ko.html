FalconMM 사용 가이드

FalconMM은 로컬 우선 미디어 라이브러리입니다. 스크린샷, 화면 녹화, 브라우저 캡처를 받은 편지함에서 검토하고, 태그 트리로 자료를 정리합니다. 선택적으로 비전 모델(VLM)을 연결해 자동으로 태그를 붙이거나, MCP를 통해 AI 어시스턴트가 라이브러리를 검색할 수 있습니다.

한국어 · v0.4.1 · 다운로드 · 모든 언어

1. 설치

  • macOS: FalconMM-0.4.1-arm64.dmg(Apple 실리콘) 또는 FalconMM-0.4.1-x64.dmg(Intel)를 내려받아 열고 FalconMM을 '응용 프로그램'으로 드래그해요. 빌드가 공증되지 않았기 때문에 처음 열 때 macOS가 물으면 오른쪽 클릭 → 열기를 선택해요(또는 '시스템 설정 → 개인정보 보호 및 보안'에서 '확인 없이 열기'를 눌러요).
  • Windows: FalconMM-Setup-0.4.1.exe를 내려받아 마법사에 따라 설치해요.
  • 첫 실행 시 라이브러리 폴더(기본값 ~/Documents/FalconMM素材库)가 만들어지고, 데이터베이스와 소재는 모두 이 컴퓨터에 저장돼요.

2. 인터페이스 언어

기본적으로 시스템 언어를 따라요(11개 언어 지원: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). '설정 → 일반 및 업데이트 → 언어'에서 언제든 바꿀 수 있고, 아랍어는 오른쪽에서 왼쪽(RTL) 레이아웃으로 표시돼요.

3. 소프트웨어 업데이트

  • 앱은 기본적으로 시작할 때 릴리스 저장소(github.com/darker2016/FalconMMRelease)의 최신 버전을 자동으로 확인해요. 설정에서 끌 수 있어요.
  • Windows: 내려받기가 끝나면 '업데이트 설치'를 눌러요. 설치 프로그램이 앱을 닫고 그 자리에서 업그레이드하며, 데이터와 설정은 모두 유지돼요.
  • macOS: '업데이트 설치'를 누르면 내려받은 DMG가 열려요. FalconMM을 '응용 프로그램'으로 드래그해 덮어쓰면 돼요. 페어링과 데이터는 그대로 유지돼요.

4. 브라우저 확장

  1. FalconMM-Extension-0.4.1.zip을 내려받아 압축을 풀어요. chrome://extensions(Edge는 edge://extensions)를 연 뒤 '개발자 모드'를 켜고 → '압축해제된 확장 프로그램을 로드합니다' → 압축을 푼 extension 폴더를 선택해요.
  2. 확장 아이콘을 눌러 안내에 따라 FalconMM과 페어링해요(설정 → 브라우저 확장 → 페어링 코드 생성).
  3. 웹 페이지에서 팝업을 열면 이미지 / 동영상을 수신함으로 가져와요. 지원 사이트의 동영상은 '현재 동영상 다운로드'로 바로 내려받을 수 있어요.

확장 프로그램 화면은 브라우저의 UI 언어를 따라요(같은 11개 언어를 지원하고, 지원하지 않는 언어에서는 영어로 표시되고, 아랍어는 오른쪽에서 왼쪽 레이아웃을 사용해요).

지원 사이트: Bilibili, Douyin, Xiaohongshu(RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. 국제 사이트는 네트워크에서 해당 사이트에 접속할 수 있어야 해요. YouTube / TikTok / X / Instagram / Vimeo에는 Tampermonkey 대체 스크립트가 없어서 파싱이 실패하면 구체적인 이유를 알려줘요. IQiYi / Youku / Tencent Video / MangoTV는 DRM으로 보호되기 때문에 다운로드를 지원하지 않아요.

5. 자주 쓰는 기능

  • 스크린샷 / 녹화: ⌘/Ctrl+Shift+U 스크린샷, ⌘/Ctrl+Shift+K 화면 녹화(설정에서 키 변경 가능). 결과는 바로 수신함으로 들어가요.
  • 수신함: 항목을 하나씩 또는 한꺼번에 '태그 달기 → 보관'으로 처리해요. 보관은 상태만 바꾸고 원본 파일을 옮기지 않으며 되돌릴 수 있어요.
  • 태그 트리: 왼쪽 트리에서 태그를 눌러 소재를 걸러 봐요. '미분류'는 시스템 노드예요. 세부 편집은 '태그 관리' 페이지에서 해요.
  • AI 태그(선택): '설정 → AI 태그'에서 OpenAI 호환 엔드포인트나 로컬 Ollama를 추가할 수 있어요. 설정하지 않아도 다른 기능에는 영향이 없어요. 인식 결과는 일단 '제안 상태'로 머물고, 확정해야 정식 태그로 기록돼요.
  • 서드파티 라이브러리 가져오기: '설정 → 데이터 보안 → 서드파티 가져오기'(Eagle / Billfish / digiKam). 원본 라이브러리는 읽기 전용으로 두고 복사해서 들여와요.
  • MCP: 설정 → MCP에서 Claude 같은 데스크톱 AI가 MCP로 소재를 검색하게 할 수 있어요.

6. 확장 개발

확장 소스 코드와 개발자 가이드는 같은 릴리스 저장소에 공개돼요(extension-source/ 디렉터리, DEVELOPER.md 참고). 사이트 추가는 확장 쪽만 고치면 돼요. 사이트 레지스트리 + 파서 + 페이지 resolver를 추가하면 확장이 핸드셰이크 때 새 사이트를 데스크톱 앱에 자동 보고해서 다운로드를 허용해요. 데스크톱 쪽 수정은 필요 없어요. 자세한 내용은 DEVELOPER.md를 참고해요.

7. 자주 묻는 질문

  • 다운로드 실패 / 빈 파일: 사이트 주소에는 서명과 유효 기간이 있어서, 먼저 페이지를 새로 고친 뒤 다운로드를 눌러요. 그래도 실패하면 오류 메시지의 구체적인 원인을 확인해요.
  • '앱이 손상되었습니다'(macOS): 공증이 없어서 생기는 현상이에요. 오른쪽 클릭으로 한 번만 열어 주면 이후 앱이 자체 검증을 마쳐요.
  • 업데이트 확인 실패: api.github.com에 접속할 수 있어야 해요. 네트워크가 제한되면 나중에 다시 시도해요.
