Guia do usuário do FalconMM

FalconMM é uma biblioteca de mídia local-first: capturas de tela, gravações de tela e capturas do navegador passam por uma caixa de entrada para revisão, uma árvore de etiquetas organiza os arquivos, um modelo de visão (VLM) pode etiquetar automaticamente (opcional), e o MCP permite que assistentes de IA façam buscas.

Português · v0.4.0 · Downloads · Todos os idiomas

1. Instalação

  • macOS: baixe o FalconMM-0.4.0-arm64.dmg (Apple silicon) ou o FalconMM-0.4.0-x64.dmg (Intel), abra e arraste o FalconMM para Aplicativos. O build não é notarizado; na primeira abertura, clique com o botão direito → Abrir quando o macOS pedir (ou use Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim).
  • Windows: baixe o FalconMM-Setup-0.4.0.exe e siga o assistente.
  • Na primeira execução é criada a pasta da biblioteca (padrão ~/Documents/FalconMM素材库); o banco de dados e os arquivos ficam no seu computador.

2. Idioma da interface

O aplicativo segue por padrão o idioma do sistema (11 idiomas: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Dá para trocar a qualquer momento em Configurações → Geral e atualizações → Idioma; o árabe usa layout da direita para a esquerda.

3. Atualizações do software

  • Por padrão, o aplicativo verifica na inicialização a versão mais recente do repositório de versões (github.com/darker2016/FalconMMRelease); dá para desativar nas Configurações.
  • Windows: depois do download, clique em Instalar atualização — o instalador fecha o aplicativo e atualiza no lugar, mantendo todos os dados e configurações.
  • macOS: clicar em Instalar atualização abre o DMG baixado; arraste o FalconMM para Aplicativos para substituí-lo. O pareamento e os dados são mantidos.

4. Extensão de navegador

  1. Baixe o FalconMM-Extension-0.4.0.zip e descompacte. Abra chrome://extensions (Edge: edge://extensions), ative o Modo do desenvolvedor → Carregar sem compactação → escolha a pasta extension descompactada.
  2. Clique no ícone da extensão e faça o pareamento com o FalconMM seguindo as instruções (Configurações → Extensão de navegador → Gerar código de pareamento).
  3. Abra o popup em qualquer página para capturar imagens / vídeos na caixa de entrada; nos sites compatíveis dá para clicar em Baixar vídeo atual.

Sites compatíveis: Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. Os sites internacionais exigem que sua rede consiga acessá-los; YouTube / TikTok / X / Instagram / Vimeo não têm script de reserva no Tampermonkey — as falhas voltam sempre com um motivo específico. IQiYi / Youku / Tencent Video / MangoTV são protegidos por DRM e não têm download.

5. Funções do dia a dia

  • Captura de tela / gravação: ⌘/Ctrl+Shift+U captura de tela, ⌘/Ctrl+Shift+K gravação de tela (teclas remapeáveis nas Configurações); os resultados vão direto para a caixa de entrada.
  • Caixa de entrada: revise os itens um a um ou em lote, “etiquetar → arquivar”; arquivar só muda o status, não move os arquivos originais e pode ser desfeito.
  • Árvore de etiquetas: clique nas etiquetas da árvore à esquerda para filtrar; “Sem categoria” é um nó do sistema; as operações avançadas ficam na página Gerenciar etiquetas.
  • Etiquetagem por IA (opcional): Configurações → Etiquetagem por IA aceita qualquer endpoint compatível com OpenAI ou um Ollama local; sem configurar, nada mais é afetado. Os resultados do reconhecimento ficam primeiro como “sugestões” e só viram etiquetas oficiais depois da confirmação.
  • Importação de bibliotecas de terceiros: Configurações → Segurança dos dados → importação de terceiros (Eagle / Billfish / digiKam); a biblioteca de origem é lida sem alterações e os arquivos são copiados para a biblioteca.
  • MCP: Configurações → MCP permite que assistentes de IA de desktop, como o Claude, encontrem seus arquivos via MCP.

6. Desenvolvimento da extensão

O código-fonte da extensão e o guia do desenvolvedor são publicados no mesmo repositório de versões (pasta extension-source/, com DEVELOPER.md). Adicionar um site mexe só na extensão: registro de sites + função de análise + resolver de página; no handshake, a extensão informa automaticamente os sites novos ao aplicativo de desktop para liberar o download, sem precisar mudar o desktop. Veja o DEVELOPER.md para detalhes.

7. Perguntas frequentes

  • Falha no download / arquivo vazio: as URLs dos sites são assinadas e expiram rápido — atualize a página primeiro e clique de novo no download; se continuar falhando, veja o motivo específico indicado no erro.
  • “O aplicativo está danificado” (macOS): é por falta de notarização — basta abrir uma vez com o botão direito → Abrir; depois o aplicativo conclui a própria verificação automaticamente.
  • Falha ao verificar atualizações: é preciso acesso a api.github.com; com a rede restrita, tente mais tarde.
