Руководство пользователя FalconMM

FalconMM — локальная медиатека: скриншоты, записи экрана и захваты из браузера попадают во входящую очередь на проверку, дерево тегов наводит порядок, визуальная модель (VLM) может автоматически проставлять теги (по желанию), а MCP позволяет ИИ-ассистентам выполнять поиск.

Русский · v0.4.1 · Загрузки · Все языки

1. Установка

  • macOS: скачайте FalconMM-0.4.1-arm64.dmg (Apple silicon) или FalconMM-0.4.1-x64.dmg (Intel), откройте образ и перетащите FalconMM в папку «Программы». Сборка не нотаризована: при первом запуске, когда macOS покажет запрос, нажмите правой кнопкой мыши → «Открыть» (или в «Системных настройках → Конфиденциальность и безопасность» нажмите «Все равно открыть»).
  • Windows: скачайте FalconMM-Setup-0.4.1.exe и следуйте шагам мастера установки.
  • При первом запуске создаётся папка библиотеки (по умолчанию ~/Documents/FalconMM素材库); база данных и материалы хранятся локально на вашем компьютере.

2. Язык интерфейса

По умолчанию приложение следует языку системы (11 языков: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Português / Русский / العربية). Сменить язык можно в любой момент: Настройки → Общие и обновления → Язык; арабский использует интерфейс справа налево.

3. Обновления приложения

  • По умолчанию при запуске приложение проверяет последнюю версию в репозитории релизов (github.com/darker2016/FalconMMRelease); проверку можно отключить в настройках.
  • Windows: после загрузки нажмите «Установить обновление» — установщик закроет приложение и обновит его на месте, сохранив все данные и настройки.
  • macOS: нажмите «Установить обновление», откроется загруженный образ DMG — перетащите FalconMM в «Программы», чтобы заменить его. Сопряжение и данные сохраняются.

4. Браузерное расширение

  1. Скачайте FalconMM-Extension-0.4.1.zip и распакуйте архив. Откройте chrome://extensions (Edge: edge://extensions), включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите распакованную папку extension.
  2. Нажмите значок расширения и выполните сопряжение с FalconMM по подсказкам (Настройки → Браузерное расширение → Создать код сопряжения).
  3. Открывайте всплывающее окно на любой странице, чтобы отправлять изображения / видео во входящие; на поддерживаемых сайтах доступна кнопка «Скачать текущее видео».

Интерфейс расширения следует языку интерфейса вашего браузера (те же 11 языков; для неподдерживаемых языков используется английский; для арабского языка — раскладка справа налево).

Поддерживаемые сайты: Bilibili, Douyin, Xiaohongshu (RedNote), YouTube, TikTok, X (Twitter), Instagram, Vimeo. Для международных сайтов нужно, чтобы ваша сеть имела к ним доступ; у YouTube / TikTok / X / Instagram / Vimeo нет резервного сценария Tampermonkey — при сбое всегда сообщается конкретная причина. IQiYi / Youku / Tencent Video / MangoTV защищены DRM, их загрузка не поддерживается.

5. Основные функции

  • Снимок экрана / запись: ⌘/Ctrl+Shift+U — снимок экрана, ⌘/Ctrl+Shift+K — запись экрана (клавиши переназначаются в настройках); результаты сразу попадают во входящие.
  • Входящие: разбирайте элементы по одному или пакетно — «поставить теги → в архив»; архивация меняет только статус, не перемещает исходные файлы и отменяется.
  • Дерево тегов: нажимайте теги в дереве слева, чтобы фильтровать материалы; «Без категории» — системный узел; расширенные операции — на странице управления тегами.
  • Теги ИИ (необязательно): Настройки → ИИ-теги принимают любой совместимый с OpenAI эндпоинт или локальный Ollama; без настройки остальные функции не затрагиваются. Результаты распознавания сначала хранятся как «предложения» и записываются как постоянные теги только после подтверждения.
  • Импорт из сторонних библиотек: Настройки → Безопасность данных → импорт из сторонних библиотек (Eagle / Billfish / digiKam); исходная библиотека открывается только для чтения, материалы копируются в библиотеку.
  • MCP: Настройки → MCP позволяет настольным ИИ-ассистентам вроде Claude искать материалы через MCP.

6. Разработка расширения

Исходный код расширения и руководство для разработчиков публикуются в том же репозитории релизов (каталог extension-source/, в нём DEVELOPER.md). Чтобы добавить сайт, достаточно изменить только расширение: реестр сайтов + функция разбора + резолвер страницы; при хендшейке расширение автоматически сообщает новые сайты настольному приложению, чтобы разрешить их загрузку, — менять настольное приложение не нужно. Подробности в DEVELOPER.md.

7. Часто задаваемые вопросы

  • Ошибка загрузки / пустой файл: ссылки сайтов подписаны и быстро устаревают — сначала обновите страницу и снова нажмите загрузку; если не помогло, смотрите конкретную причину в сообщении об ошибке.
  • «Приложение повреждено» (macOS): следствие отсутствия нотаризации — достаточно один раз открыть приложение правой кнопкой → «Открыть»; после этого приложение само завершит проверку подписи.
  • Не удаётся проверить обновления: требуется доступ к api.github.com; при ограниченной сети повторите попытку позже.
